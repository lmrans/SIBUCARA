# Dokumentasi AI Agent — SIBUCARA PRO

Dokumentasi ini berisi panduan pengembangan yang dipisahkan berdasarkan role:

- `PANDUAN_ROLE_PEMILIK.md`
- `PANDUAN_ROLE_MANDOR.md`
- `PANDUAN_ROLE_PEKERJA.md`

## Cara menggunakan
1. Letakkan folder `docs/ai-agent/` ke dalam repository project.
2. Saat mengerjakan modul Pemilik, minta agent membaca `PANDUAN_ROLE_PEMILIK.md`.
3. Saat mengerjakan modul Mandor, minta agent membaca `PANDUAN_ROLE_MANDOR.md`.
4. Saat mengerjakan modul Pekerja, minta agent membaca `PANDUAN_ROLE_PEKERJA.md`.
5. Agent wajib membaca SRS/SDD/ERD asli dalam repository dan memeriksa kode yang ada.
6. Agent harus melakukan audit terlebih dahulu dan menunggu persetujuan sebelum mengubah kode.

## Dasar dan batasan
Pemetaan FR dalam ketiga file mengikuti kolom **Stakeholder** pada tabel Daftar Functional Requirement Bab II SRS `Dokumen_SRS_Kelompok1_Fix(1).pdf` (Versi Dokumen 1.0, tanggal penyusunan 12 September 2026). Dokumen SRS juga memiliki beberapa perbedaan antara tabel FR, penjelasan FR, kebutuhan pengguna, dan daftar Use Case. Perbedaan yang berpengaruh pada hak akses ditandai secara eksplisit di panduan. Jangan menganggap catatan tersebut sebagai perubahan SRS; keputusan akhir harus ditetapkan pemilik project dan didokumentasikan.
